## 💻 Sobre o Projeto

O **SistemaGestao-Novo** foi desenvolvido para simplificar e automatizar a rotina de atendimento e gestão de salões de beleza. O sistema conta com uma interface moderna no frontend e uma API robusta no backend integrada ao banco de dados e disparo/automação de mensagens via WhatsApp.

---

## ✨ Funcionalidades

- 📅 **Agendamento de Serviços:** Controle de horários e serviços contratados.
- 👥 **Gestão de Clientes e Profissionais:** Cadastro e histórico dos clientes do salão.
- 📱 **Notificações via WhatsApp:** Integração automática para confirmações e lembretes de horários.
- 📊 **Painel Administrativo:** Visualização do fluxo de atendimentos.
